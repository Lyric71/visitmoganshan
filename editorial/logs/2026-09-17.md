## A site code fix committed with this run

`src/content.config.ts` line 210 was uncommitted in the tree when this run
started, flagged for review in the D2026-38 row notes. The news `week` regex
was `/^d{4}-d{2}$/`, which matches only the literal string `dddd-dd` and
would have refused `2026-38`; it is now `/^\d{4}-\d{2}$/`. Verified against
`editorial/scripts/news-lib.mjs` line 469, which already carried the correct
form. Without it the build fails on the dispatch. The fix is kept and
committed here.
